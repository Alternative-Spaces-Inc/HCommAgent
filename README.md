# Human Collections Agent (HCA)

Collects what a human must decide or supply, front and center over any UI, with an API that humans and AI systems call the same way. Charter: docs/HCA_CHARTER_v1.md. API skeleton: api/openapi.yaml. Ruled by Al 2026-09-29; planned by Maya; built in the factory space.
