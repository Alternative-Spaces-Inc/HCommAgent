## What is live now

- Every inbox stream envelope is an `events` row before any client sees it; the row id is the SSE `id` line.
- GET /v1/inbox/stream replays missed rows when the client sends `Last-Event-ID` (header) or `?since=`; window 24 h or 1,000 rows per tenant; same tenant and routing set rule as live delivery.
- Stream payload datetimes are ISO 8601 (FastAPI encoder), matching the HTTP responses.
