## What is live now

- Delivery is table driven: one dispatcher per event loop reads events rows above its cursor on a wake or every 2 s and hands each to the matching local queues under the P19 tenant and routing set rule. publish() writes the row and a pg_notify in the same transaction, then wakes the local dispatchers; the listener wakes them for rows other instances write. One instance today, so the listener's wake and the local wake coincide; Day 4 raises _MAX_INSTANCES to 3.
- Signature replay guard shared across instances and restarts: nonces table with a composite (device_id, nonce) key, checked after the in-memory guard; rows older than the skew window pruned every 256 calls.
- Mac app and extension remember the last SSE id line and send Last-Event-ID on reconnect, so a reconnect replays what was missed (24 h or 1,000 events) before going live. The Mac app change reaches the owner's machine at its next rebuild from main; the extension change at its next store release (0.2.1 plus).
